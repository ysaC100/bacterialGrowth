# bacterialGrowth
Simulates bacterial growth of arthrobacter globiformis with user changeable input fields(temperature, pH, nutrient availability, and initial bacterial population). This is meant to make it easier to predict the most optimal environment for a bacterial population to thrive given certain bounds. The primary functions are to read in user input for said fields, calculate the bacterial growth, and then output the growth as a graph. The future steps are to Make the graph, input section, and the whole user interactive environment more interesting to see, as well as a button to click to see the graph pop up. Python, Pandas, and ipywidgets will be used for this project.
